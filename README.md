# 🚀 Selected Work

### 🏢 ERP & E-commerce Platform

A multi-shop optical business platform evolving from an e-commerce application into an operational ERP.

**Built around:**

`Next.js` · `TypeScript` · `Node.js` · `MongoDB` · `REST APIs`

**Key areas**

* Product & inventory management
* Multi-shop architecture
* Role-based permissions
* Pricing & categories
* Suppliers
* Customer orders
* Prescription / eye-exam workflows
* POS & invoicing
* M-Pesa payment integration
* Real-time administrative workflows

> **Engineering focus:** turning a real business workflow into a maintainable software system.

---

### 📄 AI Document Extraction Pipeline

An automated document-processing backend for extracting structured information from invoices, credit notes, receipts and statements.

**Built with:**

`Python` · `FastAPI` · `AWS Textract` · `LLM APIs` · `PIL` · `Docker`

**Pipeline**

```text
Document
   ↓
Image preprocessing
   ↓
OCR / document analysis
   ↓
LLM extraction
   ↓
Structured JSON
   ↓
Business-ready data
```

Designed to handle large batches of documents while reducing manual data entry and producing structured output for downstream systems.

> **Engineering focus:** combining deterministic document processing with AI where it actually adds value.

---

### 🩺 ChaguoAI

An AI-assisted family-planning information system designed around **grounded, safety-conscious decision support**.

The architecture combines:

`WHO guidance` → `rule-based eligibility` → `ML signals` → `RAG` → `AI response`

The system is designed to keep important clinical constraints deterministic while using AI for explanation, retrieval and interaction.

**Interfaces explored:**

`WhatsApp` · `USSD` · `CHW / clinician workflows`

> **Engineering focus:** designing AI systems where the model is part of a larger controlled system rather than the entire decision-maker.
