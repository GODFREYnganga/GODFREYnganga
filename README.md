## 📄 AI Document Extraction Pipeline

An automated document-processing backend for extracting structured information from invoices, credit notes, receipts and statements.

**Technology**

`Python` · `FastAPI` · `AWS Textract` · `LLM APIs` · `PIL` · `Docker`

### Pipeline

```text
Document
   ↓
Image preprocessing
   ↓
OCR / document analysis
   ↓
LLM extraction
   ↓
Structured JSON
   ↓
Business-ready data
```

The system combines deterministic document processing with AI-based extraction to reduce manual data entry and produce structured information for downstream applications.

### Engineering focus

Building AI as part of a complete backend workflow rather than treating the language model as the entire system.

# 🧠 How I Approach Engineering

```text
             REAL PROBLEM
                  │
                  ▼
          Understand the workflow
                  │
                  ▼
            Design the system
                  │
                  ▼
          Build the core solution
                  │
                  ▼
          Integrate the components
                  │
                  ▼
            Test + debug
                  │
                  ▼
          Deploy + monitor
                  │
                  ▼
             Improve
```

I care about more than making code run.

I try to understand:

* Who uses the system?
* What problem does it solve?
* What happens when something fails?
* How does data move through the system?
* How do different services communicate?
* How can the system evolve?
